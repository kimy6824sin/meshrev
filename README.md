# meshrev — 扫描面片 → 参数化三维模型

面向活塞发动机零部件与通用机械零件的逆向建模工具。输入扫描得到的 STL 面片，自动输出：

| 输出 | 说明 |
|---|---|
| `name.py` | **参数化 CadQuery 脚本**：顶部为命名参数（孔径、层高、节圆、齿数、拔模角…），修改后重新运行即可再生成模型 |
| `name.step` | 实体模型（STEP，可导入 SolidWorks / UG / Creo / FreeCAD） |
| `name.json` | 特征树、知识校正记录、分级偏差统计 |
| `name.html` | 离线 3D 报告：扫描偏差色谱 + 重建模型叠加 + 特征树 |
| `name.png` | 偏差/模型预览图 |

## 安装与使用

```bash
pip install -e .            # numpy scipy trimesh networkx rtree shapely contourpy cadquery
meshrev 3.stl 4.stl -o out  # 或 python -m meshrev ...
meshrev 6.stl -o out --ai   # 启用 DeepSeek 设计意图审查（可选）
```

AI 审查需要 API Key，二选一（**不要提交到仓库**，`.env` 已在 `.gitignore` 中）：

```bash
export DEEPSEEK_API_KEY=sk-...        # 或在工作目录建 .env：DEEPSEEK_API_KEY=sk-...
export DEEPSEEK_MODEL=deepseek-chat   # 可选
```

## 工作原理

思路是 **"识别建模特征 + 合成比对验证"**，不是逐张拟合曲面。

1. **预处理** `prep.py`：合并顶点、剔除碎片、补小孔；用局部 PCA 估计扫描噪声 σ，后续所有阈值都随 σ 自适应。
   - 基准坐标系：主轴取主平面法向和圆柱轴向（由法线高斯球聚类、法线 PCA 得到）中面积支持最大的方向，次轴取与之正交的强方向。
   - 零点取底面（鲁棒分位数，不受尖刺干扰）。
2. **主体** `body.py`，二选一：
   - **分层拉伸**（棱柱类，如法兰、连杆、曲轴、缸体、支架）：
     - 沿主轴切片，截面基本不变的区段作为一层，层边界吸附到实测平面。
     - 截面拟合成直线/圆弧，用最小二乘拟合后在交点处连接，顶点不受噪声影响。
     - 截面均匀收缩的层识别为**铸造拔模**，用带拔模角的拉伸表示。
   - **回转**（活塞、飞轮、轴、带轮、气门）：
     - 在 (r, z) 半平面统计角向占有率，用"核心(≥0.5)+外壳滞后"提取回转轮廓。
     - 竖直段用实测点精修半径，水平段吸附到端面。
   - **齿轮/齿圈**：截面 r(θ) 做 FFT 求齿数，折叠平均得到单齿齿形，按齿数阵列；由齿顶圆反推模数并归整到 ISO 54 标准模数。
3. **精确孔** `body.axis_holes`：沿 X/Y/Z 主轴切片，找圆形内环，跨切片聚类后在面片上最小二乘拟合圆柱，测得直径、轴线偏斜和实际深度。
4. **残差特征** `residual.py`：
   - 把当前模型体素化后与扫描体素求差，每个连通块沿最佳主轴用（分层）拉伸体近似，作为加料或切除。
   - 每个候选都要通过"确实改善吻合度"的检验才保留，最多迭代 3 轮。
   - 铸件的粗糙外观、窗口、凸台、筋都走这条路，按 C 级精度用基本形状代替。
5. **机械知识校正** `knowledge.py`：
   - 孔径归整到 ISO 273 通孔、螺纹底孔、轴承座孔标准；尺寸按 1/0.5/0.1/0.05 优先归整。
   - 表面呈螺纹状起伏、直径落在"底孔径～大径"之间的孔，判定为螺纹孔，按底孔建模并标注规格。
   - 近似等径的孔统一直径（等径意图）；同轴等径孔合并为一个贯通孔（同轴镗孔意图）。
   - 孔轴线偏斜几度以内的，取与基准面垂直。
   - 自动识别圆周阵列：个数、节圆直径、起始角。
6. **CAD 生成** `cad.py`：
   - 特征树 → 可读的参数化脚本 → STEP。
   - 每个特征单独试建；OCC 拒绝的圆弧草图退回折线。
   - 布尔序列在限内存、限时的子进程里预演，会让内核崩溃的特征自动剔除。
7. **验证** `verify.py`：扫描点到模型的点面距离，按精度分级统计：
   - **A 配合/接触面**：孔、回转圆柱段/端面、基准平面，公差 max(0.05, 3σ)。
   - **B 一般面**：公差 0.3 mm。
   - **C 铸造面**（局部粗糙区域）：公差 max(0.8, 1% 对角线尺寸)。
8. **AI 审查（可选）** `ai.py`：
   - 把紧凑的特征摘要 JSON（约 1~2k token）交给 DeepSeek，判断零件类型和设计意图。
   - 只接受白名单动作：`set_d` 标准孔径（与实测相差 ≤10%）、`drop` 删除 C 级缺陷特征、`tier` 标注精度等级、`name` 参数命名，且每个动作都经过校验。
   - 无网络或无 Key 时自动跳过，纯几何流程独立可用。

其中法兰 4×Ø6.6 节圆 46、齿轮 z=30 模数 2、横孔 Ø5 都能准确还原。

## 已知局限

- 活塞内腔一类复杂铸造自由曲面只能用拉伸体粗略近似（C 级），特征数偏多。
- 非对称拔模、两端面不平行（如 4 号件）目前用台阶近似。
- 斜孔目前只在 X/Y/Z 三个主轴方向检测；非主轴方向的斜孔、油道会归入残差特征。
- 圆角、倒角没有单独建成特征（小于 C 级公差的会被忽略）。
- 螺纹、公差、材料无法从扫描得到，只给出推断标注。
